In this practice, we developed several convolutional neural networks (CNNs) to solve the classification problem posed by the STL-10 dataset (https://ai.stanford.edu/%7Eacoates/stl10/).

We used the dataset to trained different models created from scratch, and compared their performance with that of pretrained CNNs.
